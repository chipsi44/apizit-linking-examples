One explicit boundary

From Python function to local HTTP route

The function stays reusable in tests, scripts, batch jobs, or another adapter. HTTP concerns live in a small, versioned manifest.

  1. Keep the function Start with normal typed Python. No handler wrapper is required.
  2. Describe the route Link its path, method, function, and input sources in YAML.
  3. Validate statically Catch missing functions, invalid bindings, and route collisions.
  4. Preview locally Exercise the real HTTP adapter from your terminal or API client.

Designed for separation

HTTP is an adapter, not your domain

APIZIT Linking is useful when Python logic already exists or must remain independent from how it is exposed.

No code decorators

Functions do not need APIZIT Linking, FastAPI, or Flask imports. The manifest points to them using module:function.

Explicit request mapping

Bind Python parameters to path, query, header, body, form, or file inputs without passing a request object into business logic.

Validation before import

The compiler inspects Python source with the AST. Validation does not import or execute the linked customer modules.
