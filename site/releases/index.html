Canonical release channel

Release notes

PyPI is the source of installable package files. These pages are the canonical human-readable release history, with migrations kept next to every compatibility change.

Stable beta: 0.4.0. 0.5.0rc1 is also published for isolated evaluation. The final 0.5.0 package is not published, and stable examples and integrations remain pinned to 0.4.0.

Two public channels, one role each

Channel Canonical content
PyPI Installable wheel, source distribution, version, metadata, and file hashes
This GitHub Pages site Release explanation, compatibility impact, migrations, and known limits
Public changelog Compact chronological summary suitable for repository readers

This examples repository deliberately does not publish GitHub Releases for the engine. GitHub-generated source archives here would contain the examples, not the private engine source or the canonical PyPI distributions.

Published releases

Published candidate

0.5.0rc1

Useful OpenAPI 3.1, minimal documentary responses, and a release pipeline verified by nine jobs including six multi-OS clean-wheel smokes.

Stable beta

0.4.0 retrospective

Closed runtime artifact v1, strict callable drift detection, generator rejection, public schema v1, and the non-vendored APIZIT adapter contract.

Migration

0.3 to 0.4

Replace bare runtime route lists with the versioned artifact envelope, validate canonical manifests, and rebuild deployment outputs.

Evaluate the candidate separately

Release candidate, not stable: install only the exact 0.5.0rc1 package in a disposable environment. Do not interpret the candidate as final 0.5.0 or as an APIZIT promotion.

The accompanying 0.4-to-0.5 candidate evaluation guide is now applicable to the RC while keeping production on 0.4.0. It keeps manifest v1 and runtime artifact v1 distinct from the exact package engine version.

Install the current release

Terminal
python -m pip install "apizit-linking[preview]==0.4.0"
apizit-linking validate .
apizit-linking preview . --port 8080
