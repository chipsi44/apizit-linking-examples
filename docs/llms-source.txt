# APIZIT Linking

> Python APIs with clear context for AI. Write and test ordinary functions,
> define HTTP separately, and trace a route back to Python source.

Current documented version: 1.0.1, verified stable release.
Preceding stable public beta: 0.5.0. Python 3.10–3.14. Apache-2.0.

    python -m pip install "apizit-linking[preview,models]==1.0.1"
    apizit-linking validate . --json
    apizit-linking preview . --port 8080

Choose Linking for unchanged libraries, a separate inspectable HTTP manifest,
direct Python tests and controlled agent-assisted changes. Optional typed models,
HTTP/error policy, providers and guards support persistent protected JSON APIs.
Applications own storage, identity policy, backups and production deployment.
There is no portable streaming/WebSocket contract or execution sandbox.

Manifest v1 retains existing meanings; optional typed validation is explicit.
Runtime artifact v2 requires its exact compiling engine. Regenerate on upgrade.
Static validate/routes/explain/export do not import business code; --resolve-models
explicitly prepares imports and the factory. Contract diff is conservative and
cannot prove business behavior. Run direct and HTTP tests as well.
