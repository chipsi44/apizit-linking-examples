# Linking 1.0 stable release

**APIZIT Linking 1.0.1 is published and verified on PyPI.** Pin this exact stable version for reproducible installation. The earlier 0.5 line remains migration history; a stable framework version does not qualify an application's hosting, database or identity policy.

```text
python -m pip install "apizit-linking[preview,models]==1.0.1"
```

The release provides optional nested models and response filtering, body JSON pointers, HTTP status/header policies and safe domain errors, resources and permission guards, lifecycle/middleware hooks, static route composition, routes/explain/export/diff, request IDs and source fingerprints, request bounds and fresh-worker development reload. Ordinary business functions remain callable without a server or APIZIT account.

Manifest version remains 1 and legacy conversion remains the default. Runtime artifacts use format v2 and must be recompiled with the exact engine. Pydantic remains optional. Static validation imports neither factories nor models.

## Candidate history and publication status {#candidate-findings-and-publication-status}

The published 1.0.0rc1 candidate exposed a false signature mismatch with inline `Annotated[..., Field(...)]`. Corrected 1.0.1rc1 passed equivalent-metadata and changed-constraint regressions; stable 1.0.1 finalizes that corrected runtime. Module-level aliases and inline expressions are both supported.

The allocated `v1.0.0` tag published no files when GitHub execution was blocked. It was preserved and never reused. Actual registry files establish publication; an allocated tag alone does not. This stable URL records the 1.0 release family, including its first stable registry version 1.0.1.

See [migration from 0.5]({{docs}}/migrations/0.5-to-1.0/), [current limits]({{docs}}/limits/) and [standalone serving]({{docs}}/guides/standalone-serving/). The protected APIZIT `/linking/` copy and managed runtime adoption have separate dev hosting receipts. No beta or production promotion is implied.
