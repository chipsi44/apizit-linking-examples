# Linking 1.0 release candidate

Version **1.0.0rc1** is the candidate for the first stable 1.0 release. Pin the exact candidate while evaluating it; 0.5.0 remains the preceding stable beta. This page will record final publication only after the registry receipt is verified.

```text
python -m pip install "apizit-linking[preview,models]==1.0.0rc1"
```

The candidate adds opt-in nested models and response filtering, body JSON pointers, success statuses and safe headers, constant domain-error mappings, providers and permission guards, ASGI lifecycle/middleware hooks, static route-file composition, routes/explain/export/diff commands, request IDs and JSON route events, explicit request bounds and fresh-worker development reload.

Manifest version remains 1; legacy conversion stays the default. Runtime artifacts change to format v2 and require recompilation with the exact installed engine. Pydantic remains an optional extra. Static validation never imports a factory or a model.

Qualification covers unchanged-library reuse, a persistent protected SQLite API without APIZIT, and an observed request mapped to source followed by a checked change. CI tests source versions, clean wheels, minimum dependencies, real TCP restart/reload and identical double builds. These checks do not establish production hosting, search indexing, general speed or AI token savings.

See [migration from 0.5]({{docs}}/migrations/0.5-to-1.0/), [current limits]({{docs}}/limits/) and [PyPI candidate files](https://pypi.org/project/apizit-linking/1.0.0rc1/). APIZIT dev adoption and its protected `/linking/` copy are separate delivery records; no beta or production promotion is implied.
